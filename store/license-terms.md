takes the place of the Microsoft Store's Standard Application License Terms, so these terms stand on their
own. They allow what the LGPL asks a program that uses LGPL libraries to allow: changing those libraries
and reverse engineering to debug such changes (LGPL 2.1, section 6), which the standard terms forbid.

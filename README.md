# Petal

**The zero-click file converter for Windows.** Start dragging a file in File Explorer, tap a key, and
drop it on a petal of the wheel that appears under your cursor. The result is saved next to the original.

| Tap while dragging | Wheel | What's on it |
|---|---|---|
| **Shift** | Convert | Your starred favourites first, then every format the file can become (342 conversion paths) |
| **Ctrl** | Tools | Compress, metadata, edit, remove or erase, resize, watermark, crop, redact, copy text or QR, searchable PDF, read aloud, transcribe, remove noise, separate vocals, trim, split, PDF password, page numbers, sign, export Photoshop layers, file info, collect project files, colour palettes, remove pauses, animated captions, vertical video, describe a picture, table to Excel, compare two files, and for folders organize, one PDF, contact sheet, report and gather… (59 tools; more than twelve gather under More), your recipes and your own petals |
| **Alt** | Actions | Ask Petal, Share, Send to Phone, Clean for Sharing, Float, Copy, Move, Rename, ZIP, Open With, Find Duplicates, your folders, and under More: Copy Path, Copy Name, Open in VS Code, Terminal |
| **Ctrl + Win + Z**, nothing selected | Wheels without files | The app in front's shortcuts, quick actions for Windows, what's playing, and wheels of your own |

The keys can be changed in Settings. Let go of the key — the wheel stays open until you drop. Tap
another key, or turn the mouse wheel, to switch wheels in place. Drop on the centre (or press Esc) to
cancel; how much of the middle cancels can be set (Settings › The Wheel). The centre names the petal
under the cursor in full: a long name goes onto up to three lines, set in a disc that fits the hub,
instead of being cut short. A format's petal adds a few words on what it is good for ("AVIF ·
Smallest, same look"). A petal that can't do its job yet stays on the wheel, dim and dashed, and the
centre says why: an AI tool whose model isn't downloaded (choosing it opens its window, where the
download is), Open in VS Code without VS Code, a conversion that needs Ghostscript or Office.

Everything runs locally. Nothing is uploaded. Pictures and sounds dropped together are converted side
by side, one per processor core (up to four); a PDF's pages are drawn from one reading of the file and
saved together.

No drag needed: right-click files in File Explorer → **Convert with Petal** opens the same wheel at
the mouse; click a petal, use the arrow keys and Enter, or press 1 to 9 (their numbers show around
the wheel). Shift, Ctrl and Alt, Tab or the mouse wheel switch wheels. The wheel opens on the one you
used last, with the petal you chose last lit up, so Enter repeats it. A mouse side button can open
the wheel too (Settings › Keys): it then no longer goes back or forward in other apps.

**Keyboard shortcut — Ctrl + Win + Z.** With files selected in the File Explorer window in front (or
on the desktop), it opens the wheel for them; with nothing selected, it opens the wheels without files.
Press it again to close the wheel. Change it in Settings › Keys: click the button and press the new
keys. Petal asks Windows first and says so when another program already owns a combination. (Ctrl +
Win + Enter is Narrator's, which is why the default is different.) Settings › Keys can make it open
the clipboard's wheel (copied files, a screenshot, or text; a copied link becomes a QR code) or
Petal's settings instead.

**Wheels without files.** Petal's wheel also works when there is nothing to drag:

* **The app in front** — ready-made wheels for browsers (Chrome, Edge, Firefox, Brave, Opera,
  Vivaldi), File Explorer, VS Code, Word, Excel, PowerPoint, Teams, Zoom, Photoshop, Windows Terminal,
  Slack and Discord come first while their app is in front. Each petal presses that app's own
  shortcut (New Tab, Reopen Closed Tab, Command Palette, Mute, Raise Hand…); the centre shows the keys.
  Keys go only to the window that was in front when the wheel opened, and only once it is back in
  front.
* **Quick** — Windows switches that show whether they are on: dark mode, mute, the microphone, keep
  awake, hidden files, file extensions, desktop icons, Bluetooth; and Lock, Sleep, Empty Recycle Bin
  (Windows asks first), Eject Drives, Empty Clipboard, Show Desktop, Task View, Notifications, a
  screenshot of an area or the whole screen (straight onto the conversion wheel), and the clipboard's
  wheel. Some wait under **More**, a group: point at it, click it, or hold over it while dragging, and
  its petals fly out of it as glass bubbles on an orbit just outside the ring (turning away from the
  screen's edge and the wheel names); the rest of the ring steps back. Arrows, Enter and 1 to 9 work on
  the bubbles; Esc, the group again or the centre takes them back in.
* **Media** — play or pause, next, previous, shuffle, repeat and volume for whatever plays in Spotify,
  a browser or any app in Windows' media controls; the centre shows the song and its cover, turning
  while it plays.
* **Your own** — Settings › Wheels: make wheels, change any ready-made one (or put it back as it was),
  give one its own shortcut, and add petals from a search over every action, every app on the PC, and
  kinds of your own: keys to press, a program to open (or switch to when it is open), a PowerShell or
  Command Prompt script (given the clipboard, the selected text or the selected files), a folder, a
  link, a group of up to eight petals, the open windows to switch to, or the clips copied lately. A
  script that came in with imported settings is shown once before it runs.

**The screen, text and windows (1.6).** Five more ready-made wheels, and every petal can go on any
wheel:

* **Screen** — snip an area or the whole screen (saved in Pictures\Screenshots and put on the clipboard
  at once, to paste anywhere); **record** an area or a monitor to MP4 with the PC's
  sound and the microphone (a 3-2-1 countdown, a bar with the time, Stop and Cancel; the frame and the
  bar stay out of the video), then the conversion wheel opens on it, for a GIF or a smaller copy. A
  card by the clock says where a screenshot or recording was saved, with Show in Folder and Open;
  **scrolling screenshots** (Petal scrolls the area and stitches it, sticky headers once); **text from
  the screen** with Windows' OCR, QR codes and barcodes too, with Translate, Fix Keyboard Layout, Join
  Lines and Search the Web; **pin a screenshot** on top of every window; **pick a colour** with a pixel
  loupe (HEX, RGB, HSL and WCAG contrast against the colour picked before); and a **screen ruler**
  (spacing between edges, or a dragged box).
* **Draw & Present** — **draw on the screen** (pen, highlighter, line, arrow, box, ring, text, eraser,
  eight colours, three sizes, undo and redo, over the live screen, a still of it, or a white or black
  board; clicks can pass through to the apps; save or copy; P H L A R O T E, 1–3, W K F, Ctrl+Z/Y/S/C,
  Esc), **zoom** into a still of the screen with the mouse wheel and draw on what is zoomed, a
  **magnifier** that follows the pointer, a **spotlight**, **show clicks and keys** for recordings, and a
  **timer** or stopwatch on top of everything ("7", "1:30", "90s", "1h 15m").
* **Text** — on the text selected in any app: **fix keyboard layout** (ؤشف → cat, hgsghl → السلام, and
  the keyboard switches), **translate** (English to Arabic and Arabic to English with the translation
  models, a sentence at a time; the AI model when they aren't downloaded), UPPERCASE, lowercase, Title and Sentence case, remove diacritics, swap
  digits (١٢٣ ↔ 123), tidy spaces, count words, **calculate** (sums, percentages, functions and unit
  conversions in English or Arabic, answer copied), **summarize** and **rewrite** with the local AI
  model, and **dictate**.
* **Arrange** — the window in front: each petal points where it goes (up maximises, right is the right
  half, the corners are the quarters), and under More the middle, the next screen, top and bottom
  halves, always on top, see-through, minimise and close; thirds are in the picker.
* **Clipboard** — the clips copied lately as petals that paste, the clipboard history (search, pin,
  delete; private copies such as passwords are never kept; remembered after Petal closes only if you
  ask), and a new sticky note.

**Dictation — Ctrl + Win + J** in any app: speak, press it again, and Whisper on this PC types what
you said where the cursor is. Ask Petal has a microphone button too. **Sticky notes** in six colours
come back where they were. The petal you choose most for a kind of file gets a small star and is lit
when the wheel opens from the keyboard ("Your usual for JPG"). With the wheel open from the keyboard,
type **=** and a sum: the centre answers as you type and Enter copies it. Settings › Screen & Text
holds the dictation shortcut, language and accuracy, the recording defaults, every-key display and
the clipboard history switches.

**Work and sharing (1.7).** A Work wheel (palette, focus, meeting notes, captions, dictation, your
workspaces, timer, a new note), a Work submenu in the tray, and Settings › Work & Sharing:

* **Command palette — Ctrl + Win + K** anywhere: type a few letters to run any petal or action, the
  petals for the files selected in File Explorer, an installed app, a wheel, a clip, a snippet, a
  workspace, a file from the search index, a sum (answered as you type), "Ask Petal: …" or a web search.
  Initials and letters in order count ("rts" finds Record the Screen), Arabic matches with or without
  hamza, taa marbuta and diacritics, and what you choose often rises. ↑↓, Enter, Ctrl+Enter, Esc.
* **Live captions** of the PC's sound or the microphone, in a small window that never takes the focus:
  the words appear as they are said and Opus-MT puts each sentence into Arabic (in Arabic, as spoken,
  in English, or both).
* **Meeting notes** — records the PC's sound and the microphone, then writes the transcript with times
  and, with the AI model, a summary, the decisions and the action items (a long meeting is summarised
  part by part); `Documents\Petal Meetings\Meeting <date>.md` and `.m4a`.
* **Polished recordings** — after a screen recording, the camera glides in where you clicked (springs,
  not cuts), the pointer is smoothed and drawn larger, clicks get rings, and the video sits on a
  gradient with rounded corners and a shadow; the sound is kept as recorded. Off, Gentle, Medium or
  Strong zoom, six backgrounds, and a sparkles button on the recording bar to skip it once.
* **Snippets** — ";addr" becomes your address in any app, even typed with the Arabic layout on, with
  `{date}`, `{time}`, `{day}`, `{hijri}`, `{clipboard}` and `{cursor}`. Only the last 48 characters
  typed are held, in memory, and typing that programs make is ignored.
* **Workspaces** — save the apps open now and where their windows are; one petal opens what isn't
  running and puts every window back, maximised ones maximised.
* **Focus sessions** — 25, 50 or 90 minutes (or any): chosen apps go down to the taskbar whenever they
  come to the front, the sound can be muted, a pill at the top counts down with +5 and Stop, and the
  minutes of each day and the streak are kept.
* **Private Screenshot** — a screenshot with e-mail addresses, phone numbers, card numbers (Luhn),
  IBANs (mod 97), IP addresses and passwords already covered, read with Windows' OCR; Redact Photo has
  the same **Private details** button.
* **Rename by what's inside** — `{content}` in Rename: a document's title (or the AI model's
  suggestion), an invoice's sender and date, a screenshot's first words, what a photo shows.
* **Similar shots** in Find Duplicates — photos taken within two minutes of each other that look alike,
  with the sharpest one kept.
* **Send to PC** (Actions wheel, under More) — straight to another PC with Petal on the same network,
  found by a broadcast on the local network; the other PC asks before saving anything, one offer at a
  time, into `Downloads\Petal`, and names can't leave that folder. Receiving is off until you turn it on.
* **Wheel gallery and sharing** — ten ready-made wheels (Student, Presenter, Writer, Developer, Figma,
  Illustrator, Premiere Pro, Blender, Notion, Outlook), and any wheel shared as one line of text
  (`PETAL-WHEEL:…`) or a `.petalwheel` file, imported with a summary of what it holds.

**English from Arabic speech, and a progress card that steps aside (1.8.4).**

* **Accurate never asked to translate** — Whisper large-v3 turbo, the Accurate model, was trained to
  write what is said only: asked for English, it wrote garbled words in several languages. Now English
  from Arabic speech is written in Arabic with the model chosen, then translated by Opus-MT Arabic →
  English (Helsinki-NLP, 114 MB once), sentence by sentence; other languages go into English with
  Whisper's own translation by a model trained for it (Balanced or Fast). Measured on 30 FLEURS
  recordings of Arabic speech against their human English translations (BLEU, higher is better):
  Accurate's own translation 0.0, Balanced's 6.4, Fast's 2.3; Balanced + Opus-MT 25.1, Accurate +
  Opus-MT **35.6** (the AI model in its place: 20.6). Accurate also writes the Arabic itself best:
  3.9% of the letters wrong, against 9.0% for Balanced and 19.6% for Fast.
* **Arabic stays Arabic** — In Arabic used to go through English (Arabic → English → Arabic). The
  language spoken is told first (from the first half minute), and speech already in the language
  wanted is written as spoken. Transcribe, Animated Captions and Live Captions share this route
  (`SpeechText`); their windows ask for exactly the translation model the choice needs.
* **Text, too** — Translate turns Arabic into English with Opus-MT when it is here (else the AI model).
* **The progress card** — drag it anywhere, or send it to the taskbar with its new button: a taskbar
  button shows the work's name and fills with its progress, and a click on it brings the card back.
  When the work is done the card comes back by itself, and stays longer.

**Near-live captions (1.8.3).** Live captions were rebuilt so the words keep pace with a video or a
lesson instead of coming a sentence late, and never stop.

* **Words as they are said** — about every half second Whisper writes the talk since the last finished
  sentence again; the words two passes agree on are final ("local agreement", as in Whisper-Streaming),
  the newest show at once, dimmer, until they are sure. A finished sentence's sound is let go, so each
  pass stays short. Measured on a 63-second lecture fed in real time: a word is on screen 0.4 s after it
  is said on average (before: 3 s, and up to 7 s), with the same accuracy (4.5% words wrong against
  4.0%); with music under the voice, 5.5% against 9.5%, and 7% against 19% when it is loud. On a PC
  whose graphics card Whisper can't use, 2.3 s against 6–7 s, at 4–4.5% words wrong.
* **No more stalls** — the old captions waited for a pause, so music or fast talk held them back, and
  a queue dropped pieces when the PC was busy. Now nothing waits for a pause, a pass never retries at a
  higher temperature and has a time limit, and when the PC falls behind the words heard so far become
  final and the next pass starts after them.
* **Whisper's own mistakes caught** — word times aligned to the sound (DTW); where the sound stops
  mid-word Whisper sometimes makes up a sentence, and its words all fall on the same moment, so they
  are left out; words already final are found again by their text, never written twice.
* **Ready at once** — the model warms up on a moment of quiet while the bar appears (a graphics card's
  first pass takes seconds), and when the speech model chosen is too slow for the PC, a quicker one
  that is downloaded warms up and takes over by itself.
* **Translation in a lane of its own** — each finished sentence is translated properly, the sentence
  being said quickly (one candidate) in between, so the Arabic grows with the talk and a slow
  translation never holds the words up. The bar rolls over two lines, the newest words never cut off.

**More power on the wheel, and Petal in Windows (1.8).**

* **See what a petal makes** — rest on a petal and the centre says how big the result will be ("About

* **Chains** — press Space (or +) on a petal to make it a step, then drop on the last one: "Remove

* **Drags without files** — an Outlook attachment, a picture from a browser, a file from WhatsApp or

* **Quick Look** — Space on a file in File Explorer or on the desktop shows it at once: pictures,

* **Thumbnails in File Explorer** for PSD, PSB, AI, EPS, INDD, Krita and OpenRaster files (a small

* **Other programs can run petals** — a local channel for this Windows user only: `petal with webp a.png`,

  Sharing › Add to Stream Deck) with keys that run petals, open wheels and the command palette.

* **Voice commands — Ctrl + Win + M** or the microphone in the command palette: say "record the screen"

**Video, documents and AI (1.8).**

* **Record Steps** — a step-by-step guide made while you work: each click becomes a picture with a ring
  and words ("Click «Save» in Notepad", from Windows' accessibility names), typing is noted (passwords
  never), and the guide is edited, then saved as PDF, Word, a web page or Markdown.
* **A camera bubble in recordings** — your webcam in a round bubble you drag anywhere and size with the
  mouse wheel; it stays out of the screen's frames and is drawn into the video sharply, in time with it,
  polished or not.
* **Remove Pauses** — cuts the silences out of a talk, a lesson or a recording, picture and sound
  together, with a little kept at each cut.
* **Animated Captions** — the words of a video burned in, lit word by word, one word at a time or line by
  line, in Arabic or English (shaped properly), at the top, middle or bottom.
* **Vertical Video** — a wide video made 9:16 for Reels, Shorts and TikTok: following the person (with
  the background model) or what moves, from the middle, or the whole picture over a blurred copy.
* **Live Region** — part of another window (a call, a stream, a build) kept on top and live, drawn by
  Windows itself; see-through in three steps, and it closes with its window.
* **Table to Excel** — a table in a picture or on the screen (Text from the Screen › Copy as Table or
  Save as Excel) read into rows and columns, numbers as numbers, right to left for Arabic; empty cells
  are read again on their own.
* **Compare Files** — two versions of a document (Word, PDF, text, an e-book; even a PDF against its Word
  original) or two pictures: a page with the words added and removed marked in place, and the pages of
  two PDFs side by side with what changed boxed.
* **Ask Your Files** — in Search, a question ("when does the car insurance end?") is answered from your
  indexed documents by the AI model on this PC, citing the files it came from; without the model, the
  passages that mention it are shown.
* **Describe Picture** — alt text or a paragraph about a picture, written by SmolVLM (500M) on this PC,
  translated on this PC into the language Petal speaks, copied or saved in the picture's own details.

**Folders work too.** Drop a folder (or several, mixed with files) and Petal works on the files
inside, subfolders included, skipping hidden, system and temporary files. The centre shows the total
size and how many files there are. Results go to a copy of the folder beside it, with the same
subfolders — converting "Trip" to WEBP gives "Trip (WEBP)\Day 1\…" — and the original folder is
never touched. The conversion wheel offers the formats of the folder's main kind of file (pictures,
videos, music or documents) plus your favourites; files that cannot take the chosen format are left
as they are, and the card says how many. The tools wheel shows the batch tools that suit the
contents (resize, compress, watermark, metadata…, and Extract when there are archives), plus:

* **Organize Folder** — by kind (Pictures, Videos, Music, Documents, Archives…, with screenshots and
  invoices in their own folders) or by month taken (2026\2026-10), optionally renaming photos after
  the day they were taken. A live summary shows what will move; History can put everything back.
* **Folder to PDF** — every picture and PDF in the folder, in name order, as one PDF at the
  pictures' own size, A4 or Letter; optionally searchable.
* **Contact Sheet** — thumbnails of every picture with their names, 3 to 6 across, as a PDF.
* **Folder Report** — an Excel (or CSV) list of every file with its type, size, dates, picture size,
  duration and pages, plus sheets for the space each kind of file, each folder and the largest files
  take.
* **Gather Files** — copies every file (or only pictures, videos, music or PDFs) out of the subfolders
  into one flat folder, renaming clashes.

**Clean for Sharing** on the Actions wheel also takes folders, into a "(Clean)" copy.

**The actions wheel** is yours to arrange (Settings › Actions Wheel): up to eleven actions on it, the
rest under More, and up to four folders that dropped files are copied or moved to (History can undo
both). New actions: **Copy Name** (names without their folders), **Open With** (the programs Windows
suggests for the files, each opening all of them at once, or any other; nothing becomes a default) and
**Open in VS Code**.

**Make the wheel look yours** (Settings › Appearance): seven accent colours (Petal violet, the Windows
accent, Ocean, Mint, Rose, Amber, Graphite), a glass, solid or monochrome wheel, how it opens (bloom,
pop, fade, unfold or at once), soft, crisp or wooden sounds, names or icons only, a colour for any
petal (Petal Colours), and the petal under the pointer growing towards it.

**Practice and a tour.** Practice (tray menu or Settings) lets you try every wheel on a sample photo
while nothing runs: each choice says what it would have done. The welcome window has three things to
try and ticks them off, then offers a tour of Settings that points at each part in turn.

**Statistics** (tray menu or Settings) — files handled, space saved, petals used most, days in a row,
the last twelve weeks and milestones, counted on this PC only and never sent anywhere; pause or wipe
them at any time.

**Backup** (Settings) — everything (settings, wheels, favourites, recipes, automations and your own
petals) in one `.petal` file to keep or carry to another PC. Which of your petals and scripts may run
is not exported. Changes made to `settings.json` by hand are picked up at once.

**Everyday file chores, also on the wheels:**

* **Resize & Rotate** — by percentage, width, height or a box; quarter turns and flips; one photo with a
  live preview or a whole selection.
* **Add Watermark** — text (Arabic included) or a logo, placed in one of nine spots or repeated
  across; on photos, on every frame of a video, or on every PDF page. The last watermark is remembered.
* **Copy Text** — reads the text in a photo or screenshot with Windows' own OCR (every installed
  language is tried; the cleanest reading wins) and puts it on the clipboard.
* **PDF tools** — password protection with AES-256 (or removing a password you know), page numbers as
  real text, a drawn, typed or scanned signature placed on a page (a picture, not a certificate
  signature), and extracting every picture (JPEGs saved as they are, each picture once).
* **Rename** — a pattern with the name, a running number, the date a photo was taken and the folder,
  plus find & replace and letter case; previewed with clashes flagged before anything changes, and
  undone from the confirmation card.
* **Compress to ZIP** — files and folders into one archive, with an optional AES-256 password.
* **Create QR Code** (notification-area menu or the main window) — text, links or a Wi-Fi network,
  saved as PNG or SVG or copied. **Copy Text** also reads QR codes and barcodes in a picture.
* **Compress for an app** — WhatsApp, Telegram, email, Discord and other presets that keep a file
  under the app's limit.
* **Make Searchable** — scanned PDFs and photos of pages get an invisible text layer from Windows'
  OCR (Arabic included, in reading order), so they can be searched and copied; pictures become one PDF.
* **Clean for Sharing** — copies without the location, device and author details hidden in photos,
  videos, PDFs and Office files. Send to Phone offers it when a photo shows where it was taken.
* **Scan with Phone** (notification-area menu) — a QR code opens a camera page on a phone on the same
  Wi-Fi; Petal finds each page's corners, straightens it, cleans it up (colour, grey or black & white)
  and saves the pages as one searchable PDF on the PC.
* **Find Duplicates** (Actions wheel or notification-area menu) — identical files, and photos or videos
  copied at another size, in a selection or folders; extra copies go to the Recycle Bin and History
  can put them back.

**On-device AI** — nothing leaves the PC; every model is checked against a pinned SHA-256.

* **Remove Background** — BiRefNet-lite cuts out the subject (hair included) for a transparent PNG,
  a white or coloured background, optionally cropped to the subject. The 224 MB model downloads once,
  from the tool window.
* **Transcribe** — Whisper (Fast · Balanced · Accurate, the last one strong in Arabic) turns speech
  in audio or video into subtitles (.srt) and/or text, in the spoken language, in English or in Arabic
  (Arabic speech stays as it was said; Arabic into English and English into Arabic through Opus-MT,
  other languages into English by Whisper itself), and can add them to the video as a track or burned into the picture (Arabic shaped and
  right to left). Uses the graphics card through Vulkan when it can.
* **AI enlargement** in Resize — Real-ESRGAN (bundled, 4.5 MB) adds detail when a picture is made
  larger, on the graphics card through DirectML, else on the processor.
* **Read Aloud** — PDFs, Word files, e-books and text become an MP3 audiobook, with Windows' voices
  or the natural Piper voices Kareem (Arabic, diacritised automatically) and Joe (English).
* **Ask Petal** (Actions wheel) — say what to do with the files in English or Arabic ("اضغطها
  للواتساب", "make them 1080 px WEBP and zip them"). Petal shows the steps before anything runs and
  can save them as a recipe. Common requests are understood without a model; Qwen2.5 1.5B through
  llama.cpp understands requests worded freely.
* **Search by Meaning** (notification-area menu, Settings › Search) — an index on this PC of the words
  in documents, screenshots and subtitles, and of what photos and videos show (multilingual CLIP), so
  "beach at sunset" or "فاتورة الكهرباء" finds files. It reads only the folders you choose, while
  the PC is idle.
* **Remove Noise** — DeepFilterNet 3 takes hum, hiss and room noise out of speech in recordings and
  videos (the picture is copied as it is).
* **Separate Vocals** — Hybrid Transformer Demucs splits a song into vocals and music, or four parts.
* **Erase Object** — brush over a passer-by or a cable and LaMa fills the area in.
* **Arabic subtitles** — Translate to Arabic turns English SRT/VTT subtitles into Arabic with Opus-MT;
  Transcribe can write Arabic subtitles for speech in any language.

Each model downloads once from its tool window (sizes: natural voices 85 MB each, Ask Petal 1.1 GB,
search 227 MB, noise 27 MB, vocals 181 MB, eraser 208 MB, translation 114 MB each way) and is checked against
a pinned SHA-256.

**Adobe files** — no Adobe application needed:

* **Photoshop (PSD, PSB)** — convert to PNG, JPG, WEBP, TIFF, PDF and more (files saved without
  "Maximize compatibility" are combined from their visible layers); **Export Layers** saves every
  layer as a PNG named after it (Unicode names, groups, hidden layers, cropped or on the full canvas);
  **Remove Photoshop History** drops the hidden list of every file ever pasted in, which can make a
  PSD many times larger; Clean for Sharing works on PSDs too.
* **Camera RAW** (DNG, CR2, CR3, NEF, ARW, RAF, ORF, RW2 and more) — developed with the camera's white
  balance into JPG, HEIC, TIFF, PNG, WEBP, AVIF or PDF, upright, keeping the date, camera, lens,
  exposure and place.
* **Illustrator (AI)** — drawn as pictures with a transparent background, or saved as a plain PDF
  without Illustrator's editing data (often a much smaller file).
* **EPS** — the picture stored inside for previews; full-quality drawing and vector PDFs when the free
  Ghostscript is installed.
* **File Info** — size, colour mode, layers, pages or artboards, colour plates, fonts (installed here or
  not), linked files (found or missing) for PSD, RAW, AI, EPS, InDesign (INDD, IDML) and XD files.
* **Collect Files** — a Premiere Pro, After Effects, InDesign, IDML or Illustrator project with every
  file and font it uses, in one folder with a report; Premiere, After Effects and IDML copies are
  pointed at the collected files.
* **IDML** to Word, ODT, text, Markdown or HTML, in reading order; **Save Preview** for InDesign, XD and
  EPS files.
* **Swatches** — ASE (Photoshop, Illustrator, InDesign) and ACO files shown, converted into each other,
  saved as CSS, JSON, a GIMP palette or a picture; **Extract Colours** makes swatches from any picture.

**Make Petal yours:**

* **Recipes** (Settings › Recipes) — several steps as one petal on the tools wheel: remove the
  background, resize, add a watermark, convert, make searchable, rename, combine into a PDF, zip…
  Each step works on what the one before made.
* **Your own petals** (Settings › Your Petals) — a small JSON file in `%APPDATA%\Petal\petals` adds a
  tool that runs a program of your choice on the files it accepts. Petal shows the exact command
  before a petal's first run, and again whenever its file changes.
* **Favourites** (Settings › Favourites) — a format plus a longest side and a quality, such as
  "WEBP 1600" or "MP4 720p". They sit first on the conversion wheel with a star, and also make
  smaller copies of files already in that format.
* **History** (notification-area menu or Settings) — what Petal made lately, newest first: show a
  result in File Explorer, or undo it (results go to the Recycle Bin; renames are put back).
* **Automations** (Settings › Automations) — watch a folder such as Downloads and convert each new
  file once it has finished arriving (pictures, videos, audio or documents), to a format or with a
  favourite or a recipe. Results go to a "Petal" folder inside it, so a rule never feeds itself. A
  rule can also sort a folder: screenshots, invoices and everything else by kind into their own
  folders, and photos renamed after the day they were taken; History can put them back.
* **Send to Phone** (Actions wheel) — a QR code for a phone on the same Wi-Fi: it opens a page with
  the files (folders, and everything at once, as ZIP) and, when allowed, lets the phone send files
  back to Downloads. A small web server on this PC's local address under a random secret path; it
  stops when the window closes or after 15 idle minutes.
* **Command line** — `petal convert *.heic --to jpg --max 2048`, `petal resize`, `petal compress`,
  `petal zip`, `petal qr`, `petal text`, `petal codes`, `petal info`, `petal formats`, `petal run
  <recipe>`, `petal searchable`, `petal speak`, `petal ask "…"`, `petal search`, `petal denoise`,
  `petal separate`, `petal translate`, `petal layers`, `petal slim`, `petal preview`, `petal collect`,
  `petal colours`, `petal palette`. Installed as
  `Petal.com` beside `Petal.exe` (setup can add it to PATH); `petal help` lists the options.
* **Updates** — set an update address (an `update.json` over https, or a shared folder) in
  Settings › Updates and Petal checks once a day. Only a feed signed with the maker's key (ECDSA
  P-256) is offered, and the installer is verified against the signed SHA-256 before it installs
  quietly. A waiting update puts a dot on the tray icon; the tray menu can also check now. No address
  is set by default, so a plain install never phones home. `build.ps1` signs `update.json` with the
  key in `%USERPROFILE%\.petal\update-signing-key.pem`, kept out of the repository: back it up, since
  a new key would make installed copies refuse updates.

**Eight languages.** Petal speaks English, العربية, Türkçe, فارسی, اردو, Bahasa Indonesia, Français and
Español. It follows the Windows display language, and Settings › Appearance › Language switches it on
the spot. In Arabic, Persian and Urdu every window is laid out right to left; Arabic has its proper
plurals ("ملفان", "3 ملفات", "11 ملفًا"), the others their own one-and-many forms. Pictures, timelines,
waveforms and playback controls stay left to right, and digits stay Western so numbers read the same
everywhere. The right-click menu entry and the notification-area menu follow the language too.

## Install

Run `dist\Petal-Setup-1.8.4.exe` (per-user, no admin rights; the setup in English, Arabic, Turkish,
French or Spanish), or `Petal-Setup-1.8.4-arm64.exe` on ARM64 PCs with Windows 11 (built but not yet tried on ARM hardware). It includes
.NET, FFmpeg, ExifTool and the enlargement model, so nothing else is needed; the other AI models
download from their tool windows when first used. Setup can also add the `petal`
command to PATH. A portable ZIP and `update.json` (for an update feed) are built next to it.

**Microsoft Store.** `tools\scripts\build-store.ps1` packs the same release as an MSIX for the Store
(`dist\store\Petal-<version>.msix`), with File Explorer's "Convert with Petal" for every file type Petal
reads, the `petal` command, a startup task, the Store's trial and purchase, and Piper, llama.cpp and
DeepFilterNet inside, so the Store's copy downloads model data only. From the package, Petal leaves updates
to the Store. `store\` holds the listing in English and Arabic, screenshots, listing art, the privacy policy,
licence terms, third-party notices and `SUBMISSION.md`, the step-by-step guide (in Arabic) to publishing
and selling it.

Microsoft Office or LibreOffice, when installed, is used for slides and exact-layout Word/Excel output;
everything else is built in. EPS (and Illustrator files from before version 9) need Ghostscript for full
quality: all 342 conversion paths have an engine, and the 9 from EPS run when Ghostscript is installed.

## How it works

* **Gesture detection** — low-level mouse and keyboard hooks run on their own thread and only
  observe input. A drag is a press followed by a move past the system drag threshold; tapping exactly
  one mapped modifier during the drag opens that wheel.
* **The wheel is a real drop target.** It is a transparent, never-activated, topmost window registered
  with OLE. When the key is tapped it slides under the cursor while still invisible, nudges Explorer's
  drag loop, and becomes visible the moment Explorer hands it the dragged files (≈ 15–50 ms). Dropping
  on a petal returns `DROPEFFECT_COPY`, so Explorer never moves or deletes the originals. Explorer's
  drag thumbnail and native drop captions ("Convert to PNG") keep working over the wheel.
* **Frosted glass** — the pixels behind the wheel are captured just before it appears, blurred and
  saturated on the CPU, so it looks the same on Windows 10 and 11.
* **Engines** — FFmpeg (audio, video, GIF), ImageMagick via Magick.NET (images incl. HEIC, AVIF, WebP,
  SVG), PDFium / PDFsharp / PdfPig (PDF), Open XML SDK, Markdig and friends (documents, spreadsheets,
  EPUB), Microsoft Office or LibreOffice when installed (slides, exact-layout office files),
  SharpCompress (RAR, 7z), ExifTool (metadata), and Windows' own OCR and face detection.

## Building

Requirements: Windows 10 1809+ (x64), .NET 10 SDK.

```powershell
pwsh tools\scripts\fetch-tools.ps1      # FFmpeg, ExifTool and Real-ESRGAN into tools\bin (checksums verified)
dotnet build Petal.sln
dotnet test tests\Petal.Tests
src\Petal.App\bin\Debug\net10.0-windows10.0.19041.0\win-x64\Petal.exe
```

During development Petal also finds FFmpeg on the PATH or in winget's package folder.

Releases: `pwsh tools\scripts\build.ps1 -Version x.y.z -Notes "…"` (setup, ZIP and signed update feed), then
`pwsh tools\scripts\build-store.ps1 -Version x.y.z -IdentityName … -Publisher … -PublisherDisplayName …`
for the Store, with the identity values from Partner Center.

Design snapshots without a screen:

```powershell
Petal.exe --snapshots <out-folder> <background.png> <file>      # the wheel in every mode, light and dark
Petal.exe --snapshot-tools <out-folder> <test-data-folder>       # every tool window
```

Add `--lang ar` (or `--lang en`) to either command to render a specific language.

Interface text is written in English in the code and translated through `Localization/L.cs`
(`L.T`, `L.F` for formats, `L.P` for counts); the Arabic lives in `Localization/Arabic.cs`. The
localization tests fail when a new English string has no Arabic entry or a translation drops a `{0}`.
